windows

1. 해당 py파일이 있는 폴더로 이동
2. 해당 폴더에 py파일이 있는지 확인
3. conda create -n py311 python=3.11
4. conda activate py311
5. pip install deep-translator pyinstaller
6. pyinstaller --onefile --noconsole 파일.py
7. dist폴더에 exe파일이 생성되는 것을 볼 수 있다(실행 가능)
